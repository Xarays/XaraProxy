# XaraProxy

Программа для Windows с графическим интерфейсом имеющая некоторые модификации для Cloudflare WARP.
Подключение в один клик, выборочный прокси для приложений, принудительный регион для STALZONE, Kill Switch, проверка утечек и график скорости.

Автор: Xarays

## Возможности

- Подключение и отключение WARP одной кнопкой
- Два режима: warp (полный VPN) и proxy (SOCKS5, только выбранные программы)
- Автопереподключение при обрыве связи
- Выбор региона WARP и своего эндпоинта
- Активация ключа WARP+
- Проверка IP, страны и утечек DNS/IP
- Пинг регионов и эндпоинтов, автовыбор быстрого DNS
- Сканер установленных программ с категориями и запуск через прокси
- Системный прокси Windows на весь трафик
- Split tunnel (исключение доменов и IP из туннеля)
- Kill Switch через брандмауэр Windows
- Принудительный выбор региона для STALZONE (RU/EU/NA)
- Профили настроек, автозапуск с Windows, трей, звук
- Русский и английский язык интерфейса
- Тёмный интерфейс без стандартных рамок Windows

## Требования

- Windows (Проверено на 11.)
- Python 3.10+ (если запускаете из исходников)

## Установка из исходников

```
git clone https://github.com/Xarays/XaraProxy.git
cd XaraProxy
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Для Kill Switch, системного прокси и автозапуска нужны права администратора.

## Сборка exe

```
pip install pyinstaller
pyinstaller XaraProxy.spec
```

Файл появится в dist/XaraProxy.exe

## Как это работает

Программа управляет официальным warp-cli через subprocess. Она не заменяет и не патчит клиент WARP.
После подключения проверяется IP и статус через cdn-cgi/trace. Каждые 5 секунд идёт проверка статуса, при обрыве связи запускается переподключение с увеличивающейся задержкой.

Выборочный прокси запускает программы либо с флагом --proxy-server (для Chromium браузеров), либо через переменные окружения HTTP_PROXY/HTTPS_PROXY.

Для STALZONE программа ищет папку игры через Steam и стандартные пути установки, затем создаёт файл sc_forced_realm с выбранным регионом.

## Конфиг

Настройки хранятся в файле xaraproxy_config.json рядом с exe. Файл создаётся автоматически, можно удалить, он пересоздастся со значениями по умолчанию.

## Дисклеймер

Программа не связана с Cloudflare и не связана с EXBO (Разработчики STALZONE). Kill Switch и системный прокси меняют сетевые настройки Windows, используйте на свой риск.

## Прочее

Функция принудительной смены региона не запрещён правилами игры.
